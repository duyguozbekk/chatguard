# ChatGuard: Real-Time Chat Moderation (SWE015 Homework, Use Case 4)

Duygu ÖZBEK (2409011048), SWE015: Introduction to Large Language Models

A chat app that labels every message as **clean / offensive** with a confidence score, masks
offensive messages, logs the response time of every message and lets you switch between models.
The default model is a **dynamically INT8-quantized fine-tuned BERT** running on **CPU**, with a
latency budget of **50 ms per message**.

| Area | Technique | Where |
|---|---|---|
| A: Neural networks | Feedforward net trained with SGD + backprop, dropout | `src/train_w2v_ffn.py` |
| B: Classical NLP | Regex normalization (leetspeak, repeats, accents), edit-distance lexicon, tf-idf + LogReg, own word2vec | `src/normalize.py`, `src/lexicon.py`, `src/train_classical.py`, `src/train_w2v_ffn.py` |
| C: Transformers | Fine-tuned `bert-base-uncased` (WordPiece) + classification head | `src/train_bert.py` |
| D: Efficient models | Dynamic INT8 quantization, size / latency / macro-F1 benchmark | `src/quantize.py`, `src/evaluate.py` |

## Setup (macOS / Linux, Python 3.10–3.12)

```bash
git clone <this repo> && cd chatguard
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Run

**Option A: reproduce everything** (about 20–40 min on an Apple-Silicon Mac; BERT fine-tuning uses MPS/GPU if available):

```bash
bash run_all.sh        # data -> 5 models -> INT8 quantization -> evaluation (writes results/)
python app.py          # open http://127.0.0.1:7860
```

**Option B: use my trained weights.** Download `models.zip` from
**[Google Drive: models.zip](https://drive.google.com/file/d/1MxxaIamTQ9p8w8ccKdl60hVLgy4T8q9P/view?usp=sharing)**, unzip it into the repo root so that
`models/` exists, then run `python app.py`.

The model weights are not stored in this repository (see `.gitignore`).

## Data

OLID / OffensEval-2019 sub-task A (English tweets), loaded from Hugging Face
`cardiffnlp/tweet_eval` (config `offensive`). Official splits: train 11,916 / validation 1,324 /
test 860. All models are evaluated on the **same test split**.

- Zampieri et al. (2019). *Predicting the Type and Target of Offensive Posts in Social Media.* NAACL.
- Barbieri et al. (2020). *TweetEval: Unified Benchmark and Comparative Evaluation for Tweet Classification.* Findings of EMNLP.
- `lexicon/offensive_en.txt`: a hand-written word list (own data).

## Results

See `results/results.md` (generated by `src/evaluate.py`). It reports macro-F1, accuracy, size in MB
and mean / p95 CPU latency over 200 single-message runs, together with the hardware used.
`results/results.png` shows the same numbers as a chart.

## Project layout

```
app.py                  Gradio chat app (runs the INT8 BERT by default)
run_all.sh              one command that reproduces all results
src/normalize.py        regex normalization + tokenization
src/lexicon.py          minimum-edit-distance lexicon matcher (rule baseline, masking)
src/train_classical.py  rule baseline allow-list + tf-idf/LogReg
src/train_w2v_ffn.py    own word2vec (skip-gram, negative sampling) + feedforward net (SGD)
src/train_bert.py       BERT fine-tuning
src/quantize.py         dynamic INT8 quantization + loader
src/predictors.py       common predict interface for all 5 models
src/evaluate.py         test-set evaluation, size, latency, failure examples
```
